## Rules

### The regression test must be seen failing on the old code
**Source**: 2026-08-11-17.12.md, 2026-08-14-15.20.md
**Rule**: In Step 5, do not stop at "test created and passing". Temporarily revert the
fix, run the new test, confirm it fails, then restore the fix. Where the change has
several independent parts, revert them one at a time and check the matching assertion.
The suite in this project has repeatedly stayed green through user-visible breakage
(489 tests through an empty `src=""`), so a test never seen red carries no evidence.
Check regex anchors while doing it: `/\bhidden\b/` matches `aria-hidden`.

### Split "the asset does not load" into two layers before debugging
**Source**: 2026-08-11-16.59.md
**Rule**: Separate delivery from URL generation. Layer one: does a direct
`curl http://<actual-host:port>/storage/<path>` return the file (disk, symlink,
permissions)? Layer two: does the address in `src` match the address the page is served
from (URL generation)? `ERR_CONNECTION_REFUSED` instead of 404 answers this
immediately — the request never reached the server, so it is layer two. Both times this
was investigated the obvious suspects (files present, `public/storage` junction
resolving) were fine and cost time.

### Cover both sides when the fix serves opposite consumers
**Source**: 2026-08-11-16.59.md, 2026-08-11-17.12.md
**Rule**: A value consumed by parties with contradictory requirements needs one
assertion per party, in separate tests. Relative URL in page markup, absolute URL in
JSON-LD, non-empty `src` in Filament columns — the second patch exists precisely
because the first fix repaired one side and broke another with no signal at all.

### Search for string references to the attribute you are changing
**Source**: 2026-08-11-17.12.md
**Rule**: Before changing what an accessor returns, list its consumers by name, then
run a second search for the attribute as a quoted string. Filament columns reference it
as `'mainPhoto.thumb_url'`, and `with()`, `pluck()` and Blade array keys do the same —
none of these are found by grepping the method name.
