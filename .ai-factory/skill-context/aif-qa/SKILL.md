## Rules

### Assert on rendered markup for failures that leave no trace
**Source**: 2026-08-11-17.12.md, 2026-08-14-15.20.md
**Rule**: This project's recurring defect class produces no exception, no log line and
no red test — an empty `src=""` in an admin list, a dropped CSS rule, a card stack
drifting 32px from the card it labels. For these, an assertion on the rendered markup
(`not->toContain('src=""')`, presence of the exact class expression) is worth more than
an assertion on a value. Every one of the three analysed patches is this class.

### Test script-driven layout through the markup expression, not the number
**Source**: 2026-08-14-15.20.md
**Rule**: When a script computes the final value, the only thing that exists in the
response is the expression. Assert on it verbatim — `travel + hold` in the pin
wrapper's height binding, `var(--i)*var(--strip)_-_var(--shift)` in the card's `left`,
`[--shift:0px]` on the track. Simplifying any of these back is a silent return of the
defect, so the expression is the contract.

### Verify pinning and horizontal tracks by setting scroll position numerically
**Source**: 2026-08-14-15.20.md
**Rule**: Do not check scroll-driven blocks by spinning the wheel — the person testing
knows where the track ends and slows down, which yields a false green. Step through
fixed positions instead: start, end of track, middle of hold, end of hold, and a
scroll back up. At each point record the stack offset, the first and last card
position, and whether the scene is still pinned.

### Never assert against the same accessor that produced the output
**Source**: 2026-08-11-16.59.md
**Rule**: `toContain($photo->url)` compares the bug to itself and passes on broken
output. Write the expected value as a literal: `toBe('/storage/cars/img_1842.webp')`.
`CatalogShowTest` did the former and let every image on the site break.

### Give a two-sided fix one assertion per side
**Source**: 2026-08-11-16.59.md, 2026-08-11-17.12.md
**Rule**: When one change serves consumers with opposite requirements, cover each side
separately — relative URL in page markup AND absolute URL in JSON-LD AND non-empty
`src` in Filament columns. A fix that repairs one side silently breaks the other, and a
single combined assertion will not show it.
