## Rules

### Flag absolute URLs built from config for in-page assets
**Source**: 2026-08-11-16.59.md
**Rule**: An absolute URL assembled in config from `APP_URL` asserts "the app is always
reachable at this address", which fails on `artisan serve --port`, Herd, a tunnel, a
preview stand or a forwarded container port. For `src` in markup the relative address
is both shorter and more correct; absolute belongs only where the consumer requires it
(schema.org, email, Filament image columns), applied at that consumer. Add this to the
Correctness section of the checklist.

### Flag self-referential test assertions
**Source**: 2026-08-11-16.59.md
**Rule**: In the Testing section, treat `toContain($model->accessor)` — an assertion
comparing output against the same accessor that produced it — as a finding, not a
style note. It passes on broken output and is why every image on the site could break
with a green suite. Expected values belong in the test as literals.

### Flag CSS custom properties used in calc() but never declared in markup
**Source**: 2026-08-14-15.20.md
**Rule**: A `calc()` referencing an undefined custom property invalidates the entire
declaration, so an element loses the whole property, not just the term. Any variable
set only at runtime by Alpine must have a static declaration in the markup at a scope
that covers the rule using it. Same class as the `var(--font-unbounded, 'Unbounded')`
axiom already in RULES.md — the generalisation is not recorded there yet.

### Flag width units constraining a height, and the reverse
**Source**: 2026-08-14-15.20.md
**Rule**: `vw` used to size something whose real constraint is the viewport height (an
element inside a `100svh` scene), or `vh` used for a width. The two are
interchangeable only on paper: the leftover gap then depends on the window's aspect
ratio, so every visitor gets a different one and the developer may get none. This
project hit it twice inside milestone 4.12 — `22vw` for card width, then `32vw` for
card height.
