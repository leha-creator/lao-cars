## Rules

### Prove every new test fails without the fix
**Source**: 2026-08-11-17.12.md, 2026-08-14-15.20.md
**Rule**: Before reporting a task done, run each new assertion with the corresponding
piece of the change temporarily reverted, one piece at a time — not the whole change at
once. A test that was never seen red proves nothing here: in this project the existing
suite stayed green through both an empty `src=""` in every Filament image column
(489 tests) and a 32px drift between the folded card stack and the open card.
When the assertion is a regex, verify the anchor too: `/\bhidden\b/` matches
`aria-hidden`, so a guard for "hidden by default" passes on markup that has no `hidden`
class at all.

### List every consumer before changing what an accessor returns
**Source**: 2026-08-11-17.12.md
**Rule**: Changing the format of a model accessor's value (URL, formatted price, status
label) requires naming all consumers first. Switching `Storage::disk('public')->url()`
to relative paths hit six accessors (`CarPhoto::url`, `CarPhoto::thumb_url`,
`Media::url`, `Review::photo_url`, `Employee::photo_url`, `HomeContent::promoImageUrl`)
and broke a seventh class of caller nobody listed. Two consumers with opposite
requirements is the normal case, not the exception: the browser wants a relative `src`,
schema.org and Filament want an absolute URL.

### Search for string references to attributes separately
**Source**: 2026-08-11-17.12.md
**Rule**: Grep by method name does not find attributes referenced as strings —
`ImageColumn::make('mainPhoto.thumb_url')`, `with()`, `pluck()`, `->state()`,
Blade array keys. Run a second search for the attribute name as a quoted string
(`'thumb_url'`, `"thumb_url"`) whenever an accessor changes. This is how the Filament
columns were missed.

### Put the fix at the layer where the constraint applies
**Source**: 2026-08-11-17.12.md
**Rule**: When two consumers need opposite formats, wrap at the consumer that has the
narrower constraint, not in the shared accessor. `url()` was added inside the Filament
column definitions, because `ImageColumn::getImageUrl()` accepts only an absolute URL
or a disk path, while the public pages are objectively better off with a relative one.
Moving the wrap up into the accessor would fix Filament and re-break every page.

### Declare in markup any CSS variable that only a script sets
**Source**: 2026-08-14-15.20.md
**Rule**: A browser discards an entire declaration when its `calc()` references an
undefined custom property — not just the term, the whole rule. `--shift` is set by
Alpine at runtime and is declared as `[--shift:0px]` on the track for exactly this
reason: without the declaration the card loses its `left`, and with it the whole
stacking behaviour. Declare the fallback where the rule that consumes it lives —
`--shift` sits outside `lg:` because the rule it protects comes from `x-bind:class`,
which knows nothing about breakpoints. Same class as the existing
`var(--font-unbounded, 'Unbounded')` axiom in RULES.md.

### Express a viewport-height-constrained size in height units
**Source**: 2026-08-14-15.20.md
**Rule**: An element sitting inside a `100svh` scene must derive its size from the
viewport height, not its width. `clamp(380px, 32vw, 480px)` on a card inside a
full-screen pinned scene left 420px of empty field on 1440x900, and the gap grows on
every short screen — which is exactly what laptops have. This project made the same
mistake twice in one milestone (`22vw` for width collapsed the scroll distance on wide
screens, `32vw` for height opened empty space on low ones): a value taken from one axis
was applied to a constraint on the other.

### A scroll-hijacking effect must release the page with slack
**Source**: 2026-08-14-15.20.md
**Rule**: Pinning that ends exactly when its content finishes hands the page every
wheel click the visitor made on inertia — people scroll in bursts and the last click of
a burst is blind. Add a hold after the content lands, sized as a fraction of the travel
(`min(220, travel / 2)`), never a constant: the pin threshold here is 160px, so a fixed
220px would mean standing longer than you moved. The hold must contain visible motion,
not a pause — a stopped block reads as a frozen page. Any progress indicator counts the
whole distance including the hold, otherwise a full bar promises "block finished" two
clicks before it does.
