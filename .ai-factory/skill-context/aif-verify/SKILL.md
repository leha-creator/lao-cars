## Rules

### A green suite is not evidence — check that new tests were seen failing
**Source**: 2026-08-11-17.12.md, 2026-08-14-15.20.md
**Rule**: When verifying a task that added tests, confirm each new assertion was run
against the code without the fix and failed. Report "not verified against old code" as
a gap, the same way a missing test is a gap. Rationale from this project: the suite
stayed fully green through an empty `src=""` in every admin image column (489 tests)
and would have stayed green through a 32px drift between the card stack and the card it
labels. Passing tests confirm the assertion runs; only a red run confirms it guards
anything.

### Verify scroll-driven blocks in the browser at fixed positions
**Source**: 2026-08-14-15.20.md
**Rule**: Blocks that pin the page or move a horizontal track cannot be accepted by
scrolling through them — whoever checks knows where the track ends and slows down, so
the wheel always shows "looks fine". Step through explicit scroll positions (start, end
of track, middle of hold, end of hold, and back up) and record stack offset, first and
last card position, and whether the scene is still pinned at each.
