# **1\. Общее описание проекта**

«ЛАО КАРС» — компания с двумя направлениями бизнеса: импорт автомобилей (Китай, Европа и другие страны) и автосервисные услуги (ТО, ремонт, шиномонтаж, детейлинг, доп. сервисы). Сайт должен закрывать обе линейки: витрину каталога авто и продажу сервисных услуг, — и работать как основной канал получения заявок.

Документ описывает функциональность разделов сайта, состав админ-панели, оценку сроков реализации силами одного full-stack разработчика (Laravel), а также список идей для развития проекта сверх минимальной структуры.

# **2\. Технологический стек (предложение)**

* **Backend:** Laravel 11+, MySQL/PostgreSQL, очереди (Redis) для email/уведомлений.

* **Админ-панель:** Filament (быстрое развёртывание CRUD, ролей и медиа-библиотеки поверх Laravel).

* **Frontend:** Blade \+ Alpine.js для лёгких интерактивных блоков (фильтры, галереи, формы) без затрат на отдельный SPA; либо Vue-компоненты для каталога, если нужна более сложная интерактивность.

* **Инфраструктура:** Docker \+ VPS, Nginx, деплой через CI (GitHub Actions), бэкапы БД и медиа.

* **Интеграции:** Яндекс.Метрика/GA, Telegram-бот для мгновенных уведомлений о заявках, SMTP/почтовый сервис.

# **3\. Структура сайта и функциональность разделов**

## **3.1 Главная**

Цель — быстро подвести посетителя к заявке.

* Hero-блок с акцентом на импорт авто (Китай, Европа и др. страны), CTA-кнопки «Подобрать авто» и «Оставить заявку».

* Подборка актуальных/популярных моделей из каталога (динамический блок, редактируется из админки — вручную или по тегу «на главной»).

* Блок преимуществ: прозрачность сделки, юридическая проверка, помощь с оформлением (иконки \+ текст, редактируемые).

* Блок с доп. услугами (автосервис, детейлинг, доп. сервисы) — переход в соответствующие разделы.

* Форма быстрой заявки/обратного звонка, всплывающая или закреплённая в шапке.

## **3.2 Каталог автомобилей**

Ключевой раздел, определяющий сложность backend-части.

* Список автомобилей в наличии и под заказ (два статуса/раздела).

* Карточка автомобиля: фотогалерея, технические характеристики (марка, модель, год, двигатель, привод, пробег), история (страна происхождения, особенности), цена, кнопка заявки на конкретный автомобиль.

* Фильтры: марка, тип двигателя, год, цена, статус (в наличии / под заказ).

* Пагинация или подгрузка по скроллу.

* SEO: у каждой карточки — свой URL, meta-теги, микроразметка Product/Vehicle.

## **3.3 Доп. услуги (плашки в шапке)**

Второе направление бизнеса — оформляется как отдельные посадочные страницы/подразделы:

* **Автосервис —** базовое ТО, ремонт (в т.ч. гибридных авто), шиномонтаж. Список услуг с описанием и ценой (или «цена по запросу»), форма записи.

* **Детейлинг —** комплексная мойка, полировка, защита кузова, химчистка салона. Список услуг, возможно — фотогалерея «до/после», форма записи.

* **Дополнительные сервисы —** русификация мультимедиа, трейд-ин. Описание условий, форма заявки.

Каждый подраздел использует единый шаблон «страница услуги»: заголовок, описание, список позиций (управляются из админки как единая сущность «Услуга» с категорией), форма заявки с указанием выбранной услуги.

## **3.4 О компании**

* Краткая история и миссия компании (текстовый блок, редактируемый).

* Команда: карточки сотрудников (фото, имя, должность, краткая биография) — управляются из админки.

* Отзывы клиентов: список с именем, текстом, опционально рейтингом и фото; модерация публикации из админки.

## **3.5 Блог / раздел «Полезно»**

Опциональный раздел (в исходной структуре помечен вопросом «нужно ли это?») — рекомендую включить в MVP в упрощённом виде, так как это основной источник органического трафика (SEO) по низкочастотным запросам про импорт и обслуживание конкретных марок.

* Список статей с категориями (выбор авто, импорт, обслуживание конкретных марок — Zeekr, Voyah, BYD и т.д.).

* Страница статьи: текст, изображения, дата публикации, похожие статьи.

* Полноценный WYSIWYG-редактор в админке для написания статей без разработчика.

## **3.6 Контакты**

* Адрес (Москва, ул. Осенняя, 17, корп. 1), телефон, e-mail.

* Ссылки на соцсети и мессенджеры (Telegram, VK).

* Карта с маршрутом (Яндекс.Карты/2ГИС API).

* Форма обратной связи / заявки общего назначения.

# **4\. Административная панель**

Панель должна закрывать управление всем контентом сайта без участия разработчика:

* **Каталог авто:** CRUD карточек, загрузка нескольких фото, управление статусом (в наличии/под заказ/продан), отметка «показывать на главной».

* **Услуги:** CRUD услуг по трём категориям (автосервис, детейлинг, доп. сервисы), цены, описание.

* **Блог:** CRUD статей, категории, WYSIWYG-редактор, загрузка изображений.

* **Команда и отзывы:** CRUD сотрудников, модерация и публикация отзывов клиентов.

* **Заявки/лиды:** единый список заявок со всех форм сайта (с указанием источника — конкретный авто, услуга, общая форма), статусы обработки (новая/в работе/закрыта), возможность оставлять комментарии.

* **Настройки сайта:** контакты, ссылки на соцсети, тексты блока преимуществ на главной, SEO-настройки (title/description по умолчанию).

* **Медиабиблиотека:** централизованное хранилище изображений для переиспользования между разделами.

* **Пользователи и роли:** минимум — администратор и менеджер (менеджер видит заявки и каталог, но не настройки сайта).

# **5\. Оценка сроков реализации**

Оценка дана для одного full-stack разработчика (Laravel), работающего над проектом в режиме, близком к полной занятости. При параллельном подключении дизайнера сроки дизайна не суммируются с бэкендом, а идут частично параллельно.

| Этап | Содержание | Срок |
| :---- | :---- | :---- |
| 1\. Прототипирование (UX) | Карта сайта, вайрфреймы всех разделов и карточек, согласование структуры форм | 3–4 дня |
| 2\. Дизайн (UI) | Дизайн-макет в Figma: главная, каталог \+ карточка авто, 3 подраздела услуг, о компании, блог, контакты, админка (ключевые экраны) | 7–10 дней |
| 3\. Backend (Laravel) | Модели и миграции, каталог с фильтрами, услуги, блог, заявки/лиды, медиа, админ-панель (Filament), уведомления | 10–14 дней |
| 4\. Frontend / вёрстка | Blade/Alpine или Vue-компоненты, адаптивная вёрстка, интеграция с backend, формы с валидацией | 8–10 дней |
| 5\. Наполнение контентом | Загрузка карточек авто, услуг, текстов, фото, первых статей блога (совместно с заказчиком) | 3–5 дней (параллельно) |
| 6\. Тестирование и правки | Кроссбраузерность, мобильная версия, проверка форм и уведомлений, багфиксы | 3–5 дней |
| 7\. Деплой и запуск | Настройка VPS/Docker, домен, SSL, почта, аналитика, сдача проекта | 2–3 дня |

**Итого:** ≈ 5–7 недель при полной занятости одним разработчиком (с учётом параллельного дизайна и наполнения контентом). При частичной занятости (10–20 часов в неделю) — ориентировочно 9–12 недель.

Оценка не включает: съёмку/подготовку фото автомобилей и услуг, написание финального контента (тексты, статьи блога), а также интеграции сверх списка в разделе 2 (CRM, онлайн-запись с календарём и т.п. — см. раздел 6).

# **6\. Что ещё можно добавить**

## **Быстрые улучшения (низкие трудозатраты)**

* Виджет мессенджеров (WhatsApp/Telegram) с плавающей кнопкой на всех страницах.

* Избранное по каталогу (сохранение авто без регистрации, через localStorage/куки).

* Сравнение автомобилей (2–3 карточки бок о бок по характеристикам).

* Онлайн-калькулятор ориентировочной стоимости растаможки/доставки — сильный лид-магнит для темы импорта.

* Автоматические email/Telegram-уведомления менеджеру о новой заявке.

## **Функционал среднего масштаба**

* Онлайн-запись на автосервис/детейлинг с выбором даты и времени (календарь слотов).

* Личный кабинет клиента: история заявок, статус текущего заказа авто, документы.

* Расширенные фильтры каталога (диапазон цены слайдером, сортировка по популярности/цене/году).

* Раздел «Отзывы» с рейтингом и возможностью оставить отзыв через форму (с модерацией).

* Мультиязычность (en/zh) — актуально, если есть интерес зарубежных партнёров или поставщиков.

## **Стратегические доработки**

* Интеграция с CRM (amoCRM/Bitrix24) — автоматическая передача заявок и статусов сделки.

* Модуль подбора авто по анкете (бюджет, класс, страна) с выдачей рекомендаций из каталога.

* Онлайн-оплата предоплаты за бронирование услуг детейлинга/автосервиса.

* Программа лояльности/скидок для повторных клиентов сервиса.

* Раздел «Отслеживание доставки» для авто под заказ (статусы: оплачен, в пути, растаможка, доставлен).

# **7\. Допущения и риски**

* Оценка сроков не учитывает согласования и правки на стороне заказчика (обычно добавляют 20–30% к срокам).

* Готовый дизайн-макет ускорит старт разработки; при его отсутствии срок дизайна (этап 2\) входит в общий расчёт.

* Наполнение каталога реальными карточками авто (фото, характеристики) — зона ответственности заказчика, рекомендуется начинать параллельно с разработкой.

* Решение по разделу «Блог» стоит принять до старта дизайна: он влияет на структуру меню и SEO-стратегию.
