**Техническое задание (упрощённый вариант)**

**Сайт «ЛАО КАРС» на основе готового шаблона**

*версия 1.0 · июль 2026*

# **1\. Суть подхода**

Минимальный по трудозатратам вариант реализации той же структуры сайта. Индивидуальный дизайн и этап прототипирования (UX) исключены: за основу берётся готовая тема под автомобильную/дилерскую тематику (frontend-шаблон) и стандартная админ-панель Filament без кастомизации внешнего вида. Работа сводится к адаптации готового шаблона под 6 разделов структуры и подключению его к данным через Laravel.

Такой подход подходит как быстрый старт или прототип для проверки бизнес-модели, с возможностью позже перейти к индивидуальному дизайну (см. полное ТЗ).

# **2\. Технологический стек**

* **Backend:** Laravel 11+, MySQL.

* **Админ-панель:** Filament «из коробки» — стандартные формы и таблицы без переработки UI.

* **Frontend:** готовая Blade/HTML-тема автодилерского направления (лицензионная или бесплатная), адаптированная под разделы ниже.

* **Инфраструктура:** Docker \+ VPS, Nginx, базовый бэкап БД.

# **3\. Структура сайта (без изменений)**

* **Главная —** hero-блок, подборка авто из каталога (последние N штук), блок преимуществ (статичный текст), кнопка заявки.

* **Каталог —** список авто из БД, карточка с фото/характеристиками/ценой, один базовый фильтр (марка) — без сложной комбинаторики фильтров.

* **Доп. услуги —** три статичные страницы (Автосервис, Детейлинг, Доп. сервисы) со списком услуг из одной таблицы и общей формой заявки.

* **О компании —** один статичный блок текста \+ список команды из простой таблицы (без фото-биографий, если не предусмотрено темой).

* **Блог —** простой список статей и страница статьи на стандартном компоненте темы, без категорий и «похожих статей».

* **Контакты —** адрес, телефон, соцсети, встроенная карта (iframe Яндекс.Карт), форма обратной связи.

# **4\. Админ-панель (минимум)**

* CRUD по авто, услугам, статьям, команде — стандартные ресурсы Filament без доп. логики (без тегов «на главной», без сложных статусов).

* Список заявок с одной формы (без разделения по источникам).

* Одна роль — администратор (без разделения прав менеджер/админ).

* Без отдельной медиабиблиотеки — загрузка фото прямо в карточках.

# **5\. Сроки**

| Этап | Содержание | Срок |
| :---- | :---- | :---- |
| 1\. Подбор и настройка шаблона | Выбор готовой темы под автодилера, установка, адаптация цветов/логотипа под «ЛАО КАРС» | 1–2 дня |
| 2\. Backend (Laravel \+ Filament) | Модели: авто, услуги, статьи, заявки. Стандартные CRUD-ресурсы в Filament без кастомизации UI | 5–7 дней |
| 3\. Адаптация фронтенда | Подключение шаблона к данным: вывод каталога, услуг, блога, контактов из БД вместо статики | 5–6 дней |
| 4\. Наполнение контентом | Загрузка карточек авто, услуг, текстов, фото (совместно с заказчиком) | 2–3 дня (параллельно) |
| 5\. Тестирование и деплой | Проверка форм, мобильной версии, настройка VPS/Docker, домен, SSL | 2–3 дня |

**Итого:** ≈ 2,5–3 недели при полной занятости одним разработчиком.

# **6\. Что теряем по сравнению с полным ТЗ**

* Уникальный дизайн — сайт будет визуально узнаваться как шаблон, ограниченная гибкость вёрстки под бренд.

* Гибкие фильтры каталога, статусы «в наличии/под заказ», отметки для главной страницы.

* Разделение заявок по источникам (авто/услуга/общая форма) и роли менеджера.

* Категории блога, похожие статьи, карточки команды с фото и биографией.

* SEO-возможности (микроразметка, гибкие meta-теги) — зависят от возможностей выбранного шаблона.

Этот вариант закрывает базовую бизнес-задачу «показать каталог и собрать заявки» в кратчайший срок; полный функционал и индивидуальность — по мере роста, на основе полного ТЗ.
