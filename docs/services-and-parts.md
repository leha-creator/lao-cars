# Автосервис и запчасти

Как устроены блоки прайса на `/services`, откуда берутся позиции и цены, какие поля админки на это влияют, как работает выбор услуги в форме записи и что страница показывает без JavaScript. Плюс то же самое про посадочную `/parts`.

## Из чего собрана страница автосервиса

Данные для всей страницы собирает один сервис `app/Services/ServicesPageContent.php`, контроллер только отдаёт их в шаблон `resources/views/services/index.blade.php`. Порядок блоков сверху вниз — из макета v2 (`assets/mockup-v2/services.html`).

| Блок | Откуда данные | Если данных нет |
| :---- | :---- | :---- |
| Заголовок и вступление | настройки `services_page.intro_title`, `.intro_text` | заголовок из шаблона, вступления нет |
| Якорная навигация по категориям | те же категории, что и блоки прайса | навигации нет (одна категория или ни одной) |
| Блоки прайса по категориям | разделы «Категории услуг» и «Услуги и запчасти» админки | блока нет + WARN в лог |
| Описание категории | поле «Описание» самой категории | абзаца нет, **блок остаётся** |
| Оговорка о ценах | настройка `services_page.price_disclaimer` | блока нет вместе с плашкой |
| «Почему сюда» + фотопанель | настройка `services_page.advantages` | секции нет целиком |
| Форма записи с выбором услуги | те же позиции прайса | селекта нет, форма обычная |

**Пустой блок не рендерится пустым — он не рендерится вовсе.** Заголовок «Шиномонтаж» над пустым местом читается не как «мало контента», а как поломка сайта. То же с якорной навигацией: ссылка на категорию, которой на странице нет, просто не работает — и не работает молча.

Единственное исключение — **описание категории**: пустое описание убирает абзац, но не блок. Прайс важнее текста, и категория без описания остаётся на странице.

## Состав и порядок блоков

Категории — **редактируемый справочник** (`service_categories`, раздел «Контент → Категории услуг»). Заказчик заводит, переименовывает, переставляет и удаляет их сам; релиз для этого не нужен.

До вехи 4.13 категорий было ровно пять и жили они кейсами перечисления `app/Enums/ServiceCategory.php` — добавить шестую значило выкатить релиз. Перечисления больше нет; миграция перенесла пять исходных категорий в справочник, сохранив их порядок и якоря:

| Категория | Слаг (он же якорь) | Страница |
| :---- | :---- | :---- |
| ТО и ремонт | `#maintenance` | Автосервис |
| Шиномонтаж | `#tire-service` | Автосервис |
| Детейлинг | `#detailing` | Автосервис |
| Дополнительные сервисы | `#extra` | Автосервис |
| Запчасти | своя страница `/parts` | Запчасти |

**Слаг — это и есть якорь блока.** Отдельного поля «якорь» нет: второе поле с тем же значением разошлось бы с первым при первой правке. Поэтому переименование слага меняет и адрес вида `/services#detailing`, на который могут вести внешние ссылки.

**Принадлежность странице задаёт отдельное поле «Страница»**, а не имя категории. Это не формальность: до вехи 4.13 посадочная `/parts` отбирала позиции по имени категории, и переименованная из админки категория опустошила бы её молча — страница отдала бы 200, вступление и форму, но ни одного блока.

**Иконок у категорий больше нет.** Заказчик попросил снять их с заголовков 19.08.2026, и снятие сквозное: те же категории набирались тем же значком на витрине главной. Плашки блока «Экосистема» на главной значки сохранили — это плашки направлений, а не заголовки категорий, и их имена иконок записаны в шаблоне строками.

Новая категория, заведённая в админке, сама появится и блоком на странице, и ссылкой в навигации, и вкладкой в разделе позиций. Второго списка категорий в проекте нет намеренно.

## Три группы позиций внутри блока

Позиции внутри блока категории идут **тремя группами стопкой сверху вниз**, каждая своей раскладкой:

| Группа | Условие | Как выглядит |
| :---- | :---- | :---- |
| Акцентные | флаг «Акцентная» | Широкая карточка во всю ширину контента, фотография на фоне |
| С фотографией | выбрана фотография | Карточка в сетке: кадр вписан в поле 4:3, ниже название, цена и описание |
| Остальные | ни того, ни другого | Строка прайса в две колонки |

Порядок групп — прямая формулировка заказчика: «сначала показывались пункты с фото, а потом остальные». Он же решает вопрос гармонии: смешивать карточку с кадром и строку прайса в одном потоке нечем — у них разная высота и разный вес.

> ⚠️ **Поле «Порядок» действует ВНУТРИ группы, а не поверх неё.** Перетащить строку без фотографии выше строки с фотографией можно — на сайте это не изменит ничего. Группу позиции видно в таблице раздела по колонкам «Фото» и «Акцент».

**Акцентная карточка** занимает всю ширину контента: фотография подложкой, название категории мелкой разрядкой в левом верхнем углу, под ним крупно название услуги, внизу — короткое описание и жёлтая плашка цены. Ниже `lg` кадр и текст разъезжаются в поток.

**Акцентная позиция без фотографии остаётся акцентной** — та же широкая карточка, но на обычной поверхности темы. Это штатное состояние: администратор ставит флаг раньше, чем получает снимок, и страница в этот момент обязана выглядеть целой.

**Подробное описание** раскрывается на месте по кнопке «Подробнее» под карточкой. Отдельной страницы услуги нет — это прямой выбор заказчика. Без JavaScript текст виден раскрытым: так и задумано, потерять его нельзя. Пустое подробное описание кнопки не даёт.

## Прайс: что показывается и как

**Показываются только опубликованные позиции.** Снятая с публикации не выводится ни в блоке прайса, ни в списке услуг в форме — это один и тот же набор.

**Порядок внутри блока** — поле «Порядок» позиции, удобнее задавать перетаскиванием строк на вкладке категории в админке. Порядок действует внутри своей группы — см. выше.

**Цена собирается из двух полей** — суммы и уточнения к ней:

| Цена | Уточнение | Как выглядит на сайте |
| :---- | :---- | :---- |
| 6500 | `от` | **от 6 500 ₽** |
| 1200 | `за колесо` | **1 200 ₽ за колесо** |
| 3200 | — | **3 200 ₽** |
| пусто | — | по запросу (приглушённо, без акцента) |

Позицию уточнения определяет само уточнение: предлоги **«от»** и **«до»** ставятся перед суммой, любой другой текст — после. Отдельного поля «префикс или суффикс» нет — это была бы миграция ради вёрстки.

> ⚠️ Написав уточнение вроде «начиная от» или «за комплект», вы получите грамматически неверную строку («12 000 ₽ начиная от»), а не ошибку. Пользуйтесь короткими формами: «от», «до», «за колесо», «за сезон».

«По запросу» набирается приглушённо, а не акцентом наравне с суммой: акцент обещал бы цену, которой в строке нет.

**Микроразметки цен для поисковика нет — осознанно.** Прайс сопровождается оговоркой «цены ориентировочные», а разметка `Offer` с полем `price` — это обещание поисковику фиксированной суммы. Расхождение цены в сниппете и на странице даёт претензию, а не трафик. Если заказчик зафиксирует цены как публичные, разметку соберём тем же приёмом, что на карточке автомобиля.

## Выбор услуги в форме записи

Форма внизу страницы — та же `x-lead-section`, что на остальных страницах разделов, но с дополнительным полем **«Интересует»**: списком опубликованных позиций, сгруппированным по категориям.

```blade
<x-lead-section :services="$services" title="Записаться на сервис" submit="Записаться" />
```

**Что попадает в заявку:**

| Что выбрал посетитель | Источник заявки в админке |
| :---- | :---- |
| Конкретную позицию прайса | «Услуга: Полировка кузова» |
| «Нужна консультация» (первый вариант) | «Общая форма» |

Именно эта связь даёт менеджеру название услуги в списке заявок и в Telegram-уведомлении. Свободное текстовое поле «Интересует» выглядело бы так же, но заявка потеряла бы связь с позицией прайса — а вместе с ней и возможность понять, что именно человек читал перед отправкой.

**Клик по строке прайса подставляет позицию в этот список и прокручивает к форме.** Строки прайса при этом — обычные ссылки на `#lead-form`, поэтому:

- **со скриптом** — клик по «Полировке кузова» выбирает её в списке и уводит к форме;
- **без скрипта** — клик уводит к форме, а позицию посетитель выбирает в списке сам.

Форма работает в обоих случаях. Список не «умный» и не обязательный: заявку можно отправить, ничего в нём не выбрав.

**Если позицию сняли с публикации, пока посетитель заполнял форму**, заявка будет отклонена с сообщением рядом с полем «Интересует». Введённые имя, телефон и комментарий при этом сохраняются — заполнять заново ничего не нужно, достаточно выбрать другую позицию или «Нужна консультация».

## Страница запчастей

`/parts` устроена проще: у неё нет сервиса-прослойки, всё собирает `app/Http/Controllers/PartsController.php`.

| Блок | Откуда данные | Если данных нет |
| :---- | :---- | :---- |
| Заголовок и вступление | настройки `parts_page.intro_title`, `.intro_text` | заголовок из шаблона, вступления нет |
| Позиции подбора | категории со страницей «Запчасти» в справочнике | секции нет + WARN в лог |
| Условия поставки | настройка `parts_page.delivery_terms` | блока нет |
| Форма подбора | компонент `x-lead-section` с полями авто | не бывает пустой |

**Позиции выводятся карточками, а не прайсом**, и цена в карточке показывается только там, где заполнена. Фолбэка «по запросу» здесь нет намеренно: у всех позиций цена пустая, и пять одинаковых подписей в столбик — шум, а не информация. На странице автосервиса тот же фолбэк осмыслен, потому что там у соседних позиций суммы есть.

**Позиции с фотографией и без неё стоят в одной сетке**, с фотографией — выше. Разметка карточки та же, что на странице автосервиса: два по-разному набранных вида одной карточки разъехались бы на первой же правке одной из них.

Категорий у этой страницы может быть несколько — сегодня она одна («Запчасти»), а позиции внутри неё читаются как категории. Блоков по категориям здесь пока нет: развести «Оригинальные детали» и «Аналоги» отдельными блоками с описаниями станет осмысленно, когда заказчик этого попросит.

> ⚠️ **Последнюю категорию страницы «Запчасти» удалить нельзя, и сменить ей страницу тоже нельзя.** Оба действия оставили бы посадочную страницу подбора без единого блока при живом пункте меню — админка объяснит это и отменит действие.

**Форма подбора источник заявки не проставляет.** Заявку на подбор отличают поля автомобиля клиента — марка, модель и VIN: менеджер всё равно идёт к поставщику по VIN, и категория без артикула ему ничего не добавляет. Если менеджеры попросят разделять заявки по категориям запчастей — вернёмся к этому.

## Что правится в админке

### Категории услуг

**Контент → Категории услуг.** Справочник устроен как справочник марок автомобилей: название, слаг, порядок перетаскиванием.

| Поле категории | Что меняет на сайте |
| :---- | :---- |
| Название | Заголовок блока и подпись в якорной навигации |
| Slug | Якорь блока (`/services#detailing`) — внешние ссылки на него сломаются при правке |
| Страница | Где выводится категория: блоком на `/services` или карточками на `/parts` |
| Описание | Абзац под заголовком блока; пустое убирает абзац, но не блок |
| Порядок | Место блока на странице |

**Категорию с позициями удалить нельзя** — сначала перенесите или удалите позиции. **Последнюю категорию страницы «Запчасти» нельзя ни удалить, ни перевести на другую страницу.**

### Позиции прайса и категории запчастей

**Контент → Услуги и запчасти.** Название, описание, цена, уточнение к цене, порядок и публикация — см. [«Контент и настройки»](admin-content.md#услуги-и-запчасти).

Что влияет на страницу автосервиса:

| Поле позиции | Что меняет на сайте |
| :---- | :---- |
| Категория | В каком блоке окажется позиция (и окажется ли на этой странице вообще) |
| Фотография | Вид карточки: с кадром позиция уходит в группу выше строк прайса |
| Акцентная | Широкая карточка во всю ширину контента, самая верхняя группа блока |
| Подробное описание | Текст под кнопкой «Подробнее»; пустое — кнопки нет |
| Публикация | Видна ли позиция в прайсе и в списке «Интересует» |
| Порядок | Место позиции **внутри своей группы** |
| Цена + уточнение | Правую часть строки прайса или плашку цены в карточке |
| Название | Левую часть строки и подпись в списке «Интересует» |

Описание позиции в **строке прайса** не выводится — прайс это список названий с ценами. В карточке (с фотографией или акцентной) описание видно, и на посадочной запчастей тоже.

**Как выбрать фотографию.** Поле «Фотография» в секции «Оформление» открывает медиабиблиотеку — тот же выбор, что у сотрудников и отзывов.

**Кадр в карточке сетки вписывается целиком** (веха 4.14): пропорция 4:3 остаётся у контейнера — он держит сетку ровной, — а снимок любых пропорций помещается в него без обрезки, поля закрываются фоном. Подгонять кадр под 4:3 заранее не нужно.

Изначально веха трогала только карточки автомобилей: заказчик говорил про них. Решение пересмотрено на приёмке — посетитель видел вписанный кадр в каталоге и обрезанный в услугах, а болезнь у них одна: у вертикального снимка исчезают верх и низ.

**Акцентная карточка кадр по-прежнему обрезает**, и это не забытая правка: там фотография лежит ПОДЛОЖКОЙ под названием, ценой и описанием, то есть работает фоном, а не изображением товара. Вписанный фон оставил бы поля вокруг текста. Пропорции те же: широкая полоса на десктопе и 5:4 на телефоне, снимок с важной деталью у самого края обрежется.

> ⚠️ **Фотографий услуг у заказчика пока нет ни одной, и сид их не проставляет намеренно.** Взять кадры этапов покупки нельзя: одна фотография в двух ролях на одном сайте читается как ошибка. Пока фотографии не появятся, страница показывает только строки прайса — это штатное состояние, а не поломка.

Файл, выбранный в услуге, **считается занятым**: медиабиблиотека покажет строку «Услуга: …» в перечне использования и не даст удалить его молча.

### Тексты блоков страницы автосервиса

**Настройки сайта → вкладка «Автосервис и запчасти»:**

| Поле в админке | Ключ настройки | Что это на странице |
| :---- | :---- | :---- |
| Автосервис: заголовок | `services_page.intro_title` | H1 страницы и заголовок вкладки браузера |
| Автосервис: вступление | `services_page.intro_text` | Абзац под заголовком |
| Автосервис: оговорка о ценах | `services_page.price_disclaimer` | Блок под прайсом с плашкой «Не публичная оферта» |
| Автосервис: почему сюда | `services_page.advantages` | Карточки рядом с фотографией мастерской |
| Запчасти: заголовок | `parts_page.intro_title` | H1 страницы `/parts` |
| Запчасти: вступление | `parts_page.intro_text` | Абзац под заголовком |
| Запчасти: условия поставки | `parts_page.delivery_terms` | Блок под категориями |

**Описаний категорий на этой вкладке больше нет.** До вехи 4.13 они лежали здесь одной настройкой с полем на каждую категорию; теперь описание правится там же, где заводится сама категория, — в разделе «Контент → Категории услуг». Со справочником, который редактирует заказчик, старая настройка превращалась бы в мусор при первом же удалении категории: поле в форме исчезает, значение остаётся в базе навсегда и никому не видно.

### Поведение при пустых значениях

| Что очистили | Результат |
| :---- | :---- |
| Заголовок автосервиса | Подставляется «Автосервис» из шаблона |
| Вступление | Абзаца нет, заголовок остаётся |
| Описание категории (в справочнике) | Абзаца нет, **блок прайса остаётся** |
| Подробное описание позиции | Кнопки «Подробнее» нет |
| Оговорку о ценах | Блока нет целиком, вместе с плашкой «Не публичная оферта» |
| Все карточки «Почему сюда» | Секции нет целиком, вместе с фотографией мастерской |
| Условия поставки запчастей | Блока нет |

Плашка «Не публичная оферта» исчезает вместе с текстом оговорки намеренно: плашка без пояснения ничего не сообщает.

> ⚠️ Текст оговорки юридически значим. Он живёт в настройках именно затем, чтобы правиться без разработчика, — но и удалить его можно одним движением. Прайс без оговорки читается как фиксированные цены.

## Фотография мастерской

Фотопанель блока «Почему сюда» — **часть вёрстки**, а не редактируемый контент: из админки она не меняется.

| Файл | Где используется | Вес |
| :---- | :---- | :---- |
| `resources/images/service-panel.webp` | Блок «Почему сюда» на `/services` | ~109 КБ |

> ⚠️ Сейчас там стоковая фотография из макета — на проде её обязан заменить заказчик. Права на исходник не проверялись.

Подпись поверх фотографии живёт в шаблоне, а не в настройках: она описывает конкретный кадр («тот же сервис, что готовит наши автомобили к выдаче») и меняется только вместе с ним.

Подпись лежит на градиентной маске, и вехой 4.11 её стопы пересчитаны. Обе страницы, где стоит эта панель (`/services` и главная), стали светлыми, а маска рассчитывалась на тёмную тему: приглушённый СВЕТЛЫЙ текст читается и через полупрозрачный слой, а тёмный поверх мутного серого — нет. Непрозрачная часть поднята к 30% высоты, ровно под подпись; середина и верх кадра остались прежними. Панели на двух страницах обязаны оставаться одинаковыми — кадр у них один.

**Как заменить** — так же, как фоны главной: положить файл под тем же именем в `resources/images/` и выполнить `npm run build`. Подробности и требования к файлу — в [«Главной странице»](homepage.md#фоновые-фотографии).

## Если прайс не наполнен

Позиции засеяны для разработки, а на проде их заводит заказчик. Пока этого не произошло:

- страница автосервиса состоит из заголовка, формы и блока «Почему сюда»;
- посадочная запчастей — из заголовка, условий поставки и формы;
- в `storage/logs/laravel.log` на каждый показ страницы пишется предупреждение:

```
[Автосервис] на странице нет ни одной опубликованной позиции прайса
[Запчасти] в категориях страницы нет ни одной опубликованной позиции
```

У каждой из страниц предупреждений **два, и чинятся они по-разному**:

```
[Автосервис] на странице нет ни одной категории
[Запчасти] на странице нет ни одной категории
```

Это уже не про позиции: у страницы нет ни одной категории в справочнике. Публиковать позиции некуда — сначала заведите категорию с нужным значением поля «Страница» в разделе «Категории услуг». Состояние стало достижимым вместе со справочником: до вехи 4.13 категорий было ровно пять и убрать их было нельзя, а теперь достаточно переключить всем поле «Страница».

Третье предупреждение приходит с главной:

```
[Главная] плашка экосистемы ссылается на несуществующую категорию
```

Плашки «Автосервис» и «Детейлинг» в блоке «Экосистема» ведут на якоря блоков `/services#maintenance` и `/services#detailing`. Слаг категории правится из админки, и после переименования плашка ведёт на страницу услуг без прокрутки к блоку. Лечится возвратом прежнего слага или правкой списка `ECOSYSTEM_ANCHORS` в `app/Services/HomeContent.php`.

Это не ошибка кода, а незаполненный контент: лечится в разделе «Услуги и запчасти» админки, а не правкой шаблона. **Снаружи страница при этом выглядит работающей** — она отдаёт 200 и нормальную вёрстку, поэтому заметить проблему больше нечем, кроме лога.

## Диагностика

| Симптом | Причина | Что делать |
| :---- | :---- | :---- |
| Блока категории нет на странице | Ни одной опубликованной позиции в этой категории | Опубликовать позиции в разделе «Услуги и запчасти» |
| Ссылки категории нет в навигации | То же — навигация строится из тех же блоков | То же |
| Навигации нет вовсе | Осталась одна категория с позициями | Так и задумано: листать нечего |
| Позиции нет в прайсе | Снята с публикации | Включить публикацию в списке позиций |
| Позиции нет в списке «Интересует» | То же — это один и тот же набор | То же |
| Вместо суммы «по запросу» | Цена не заполнена | Заполнить цену; пустая цена и означает «по запросу» |
| Уточнение к цене оказалось не с той стороны | «от» и «до» идут перед суммой, всё остальное — после | Использовать короткую форму уточнения |
| Описание категории не видно | Поле «Описание» самой категории пустое | Заполнить его в разделе «Категории услуг» |
| Перетащил позицию, на сайте порядок прежний | Порядок действует внутри группы: акцентные → с фотографией → остальные | Смотреть колонки «Фото» и «Акцент» в таблице позиций |
| Позиция с фотографией стоит не там, где ждали | То же: она в своей группе, выше строк прайса | Так и задумано |
| Кнопки «Подробнее» нет | Поле «Подробное описание» пустое | Заполнить его в секции «Оформление» |
| Фотография услуги пропала | Файл удалён из медиабиблиотеки | Выбрать снимок заново; библиотека предупреждает об использовании перед удалением |
| Категорию не удалить | За ней числятся позиции либо это последняя категория страницы «Запчасти» | Перенести позиции или завести вторую категорию запчастей |
| Страницу категории не сменить | Это последняя категория страницы «Запчасти» | Сначала завести другую категорию этой страницы |
| Плашка экосистемы ведёт на `/services` без прокрутки | Слаг категории переименован | Вернуть прежний слаг или поправить `ECOSYSTEM_ANCHORS` |
| Посадочная запчастей пуста при заведённых позициях | У категории этих позиций поле «Страница» — «Автосервис» | Переключить поле «Страница» у категории |
| Страница услуг пуста при заведённых позициях | Ни одной категории со страницей «Автосервис» в справочнике | Завести категорию или переключить поле «Страница»; в логе стоит WARN |
| Блок «Почему сюда» пропал вместе с фотографией | Удалены все карточки репитера | Добавить хотя бы одну карточку |
| Правка в админке не видна на сайте | Кеш настроек | Сохранить настройку повторно; вручную — `php artisan cache:clear` |
| Заявка не сохранила выбранную услугу | Позицию сняли с публикации во время заполнения | Выбрать другую позицию или «Нужна консультация» |
| Клик по строке прайса не выбирает позицию в списке | Скрипт не загрузился либо прайс и форма разъехались по разным `x-data`-обёрткам | Проверить консоль браузера; обёртка обязана охватывать и прайс, и секцию заявки |
| Фотография мастерской не отображается | Файла нет в сборке | `npm run build`; проверить имя файла в `resources/images/` |
| `laravel.log` растёт предупреждениями про прайс | Позиции не заведены | Наполнить раздел; убирать предупреждение не нужно |
